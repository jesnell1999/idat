## 1. Problema y Oportunidad

🧩 **Problema**: Instituciones públicas reciben miles de preguntas repetidas que demoran en responder.  
🕒 Atención presencial = colas, frustración y costos altos.  
📄 Documentos oficiales son extensos, poco comprensibles y dispersos.

✨ **Oportunidad**: Crear una solución con IA que escuche, entienda y resuelva preguntas reales en segundos.

---

## 2. Visión del Producto: Pregúntame.pe

📌 **¿Qué es?** Un asistente digital que responde dudas frecuentes usando reglamentos reales como fuente.

👥 **¿Para quién?** Ciudadanos, estudiantes, administrativos, visitantes.  
🌐 **¿Dónde funciona?** Web, Telegram, WhatsApp o cabinas digitales.  
⚙️ **¿Qué hace?** Responde preguntas con claridad, con fuente incluida.

🎯 **Propósito**: Acercar la información oficial a las personas, sin complicaciones ni filas.

---

## 3. Herramientas Clave con Justificación

| Herramienta                         | ✅ ¿Por qué la usamos?                           | 🛠️ ¿Qué hace?                                                       |
| ----------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------ |
| **GPT-4o** 🤖                        | Modelo IA más avanzado de OpenAI                | Genera respuestas naturales y personalizadas                       |
| **Embeddings** 🧠                    | Entiende el significado semántico de documentos | Encuentra respuestas precisas desde PDFs                           |
| **Supabase** 📦                      | Almacena preguntas, documentos y registros      | Administra sin saber backend                                       |
| **LangChain** 🔁                     | Conecta IA + documentos + flujo de respuesta    | Automatiza la búsqueda + generación                                |
| **Vercel / Render** 🚀               | Hospedaje gratuito y moderno                    | Mostrar el producto a usuarios reales                              |
| **Telegram Bot** 📲                  | Contacto directo y sin fricción                 | Canal ideal para ciudadanos                                        |
| **ChatGPT + Imágenes integradas** 🖼️ | Genera pantallas, flujos y logos con solo texto | Prototipado sin diseñador                                          |
| **Lovable.dev** 💖                   | Editor de producto impulsado por IA             | Diseña propuestas de valor, canvas, usuarios y roadmaps en minutos |

## 6. Prompt Maestro y Ejemplos Avanzados

### 🎓 Prompt maestro para contextualizar a ChatGPT

```
Actúa como un experto mundial en inteligencia artificial aplicada a la atención ciudadana. Has liderado proyectos públicos usando GPT-4o, embeddings, bots y prototipado visual con IA. Proporciona: estructura del producto, diseño del flujo, sugerencias de UX, prompts para imagen, nombre, logo, métricas y más.
```

---

### 📷 Prompt para generar interfaz visual

```
Diseña una pantalla para Pregúntame.pe con: campo de texto, botón enviar, respuesta debajo, avatar institucional, botón “ver fuente” y accesibilidad para adultos mayores.
```

### 🖼️ Prompt para logotipo

```
Crea un logotipo accesible, moderno y representativo para el asistente Pregúntame.pe. Inspiración: ciudadanía, confianza, claridad.
```

### 📄 Prompt para ideas de preguntas reales

```
Escribe 15 preguntas frecuentes que recibe una universidad pública del Perú. Lenguaje simple. Temas: becas, matrículas, constancias, pagos, horarios.
```

### 🧪 Prompt para funcionalidades extra

