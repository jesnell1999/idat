## 1. Identificar el Problema Real

🎯 Piensa en algo que te frustra, algo que se hace lento, repetitivo o desordenado.

📋 Hazte estas preguntas:
- ¿Qué problema vale la pena resolver?
- ¿A quién afecta más?
- ¿Qué tareas repetitivas existen que podrían automatizarse?

📍 Escribe el problema en 1 párrafo claro y emocional.

---

## 2. Crear la Visión del Negocio

💡 Define tu idea usando esta estructura:

- **¿Qué es?** → Ej: Un asistente, una app, un servicio
- **¿Para quién es?** → Público objetivo claro
- **¿Qué hace con IA?** → Lo que automatiza o mejora
- **¿Dónde se usa?** → Canales digitales (Web, App, Telegram, etc.)

✏️ Usa [Lovable.dev](https://lovable.dev/) para:
- Redactar tu propuesta de valor
- Definir arquetipos de usuario
- Crear tu hoja de ruta inicial (roadmap)
- Escribir la visión y misión del negocio

## 4. Diseñar el Flujo del Servicio o Producto

📌 Pregúntate: ¿Qué pasos realiza el usuario desde que entra hasta que se va feliz?

💭 Dibuja el flujo (puede ser en texto o IA visual). Ejemplo:

```ascii
🧑 Usuario
   ↓
📱 Interfaz (web / app / chat)
   ↓
💬 Escribe su duda / tarea / necesidad
   ↓
🤖 IA responde / recomienda / ejecuta
   ↓
✅ Usuario resuelve su problema
```

## 5. Prototipar Visualmente con IA

🎨 Usa IA para crear una **versión visual** de tu negocio:

- 🖼️ Prompt para pantalla de inicio:
```
Diseña una pantalla principal para una app llamada [Tu Idea], donde el usuario puede ingresar una solicitud y recibir una respuesta automática.
```

- 🎯 Prompt para propuesta visual:
```
Crea una propuesta visual para una solución que use inteligencia artificial para ayudar a [grupo objetivo] a [resolver problema específico].
```

- 📷 Prompt para logotipo:
```
Diseña un logotipo moderno y accesible para [nombre de tu negocio]. Debe transmitir innovación, confianza y simplicidad.
```

---

## 6. Usar Prompts para Crear con IA

🧠 Comienza siempre con un **prompt maestro** que contextualice tu proyecto:

```
Actúa como un experto en creación de negocios basados en inteligencia artificial. Ayúdame a diseñar una solución llamada [nombre] que ayude a [grupo de personas] a resolver [problema] mediante IA. Propón funcionalidades, flujo de servicio, visuales y métricas clave.
```

Luego puedes pedirle a la IA:
- Simular usuarios reales
- Redactar preguntas frecuentes
- Sugerir funciones nuevas
- Medir impacto y beneficios esperados

## 7. Presentar tu Idea como CEO

🎤 Prepara tu pitch con estos elementos:

- 🔍 El problema que resuelve
- 🌟 Qué lo hace único con IA
- 👥 A quién beneficia
- 📊 Resultados que promete
- 💬 Frase final con emoción

💻 Ejemplo de código de cierre:

```python
idea = "MiProductoAI"
impacto = "automatiza tareas aburridas para miles de personas"

```
